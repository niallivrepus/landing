## 🌈 What is Gooey?

**Gooey** is a standalone, headless design system built for expressive interfaces. It's an independently deployable UI package — no dependencies on any app codebase. Just pure, colorful, animated components.

It ships with:

- 🎨 **113 UI components** across 10 categories
- 🌊 **189 design tokens** — energy scales, precious metals, minerals, factions, origins
- ✨ **9 spring animation presets** + 7 CSS keyframe animations
- 🔤 **4 font families** with 42 typographic styles
- 📐 **4 responsive breakpoints** with a 12/6-column grid
- 🪄 **Special effects** — mineral overlays, spectral borders, liquid glass, confetti, fireworks
- 🌙 **Dark + Light themes** with automatic token inversion

## ✨ Effects & Animation

### 🧬 Spring Presets

9 physics-based spring animations powered by [Motion](https://motion.dev):

| Preset | Stiffness | Damping | Character |
|---|---|---|---|
| `gentle` | 350 | 25 | Soft, organic |
| `standard` | 550 | 30 | Default feel |
| `snappy` | 650 | 30 | Quick response |
| `bouncy` | 500 | 20 | Playful bounce |
| `microPop` | 1000 | 35 | Tiny, instant |
| `smooth` | 450 | 35 | Silky movement |
| `familyDialog` | 750 | 38 | Dialog entrances |
| `familySnap` | 850 | 42 | Snap-to-place |
| `familyBounce` | 650 | 25 | Elastic settle |

### 🎭 Micro-interactions

- **Hover**: scale 1.02, gentle spring
- **Tap**: scale 0.96, snappy spring
- **Focus**: scale 1.01, gentle spring

### 🌊 CSS Animations

`wiggle` · `typing` · `storyGlow` · `skeletonPulse` · `skeletonShine` · `shootingStar` · `spectral-shine` · `liquidGlassNoise`

### 🪄 Special Effect Classes

| Class | What it does |
|---|---|
| `.mineral-effect` | 2-layer gradient overlay (33% opacity, overlay blend) |
| `.mineral-effect-strong` | Same at 50% opacity |
| `.mineral-effect-subtle` | Same at 20% opacity |

| `.liquid-toggle` | Backdrop blur with gooey filter |

## 🪝 Hooks & Utilities

### Hooks

| Hook | Returns |
|---|---|
| `useTheme()` | `{ theme, resolvedTheme, setTheme, isDarkMode }` |
| `useReducedMotion()` | `boolean` — respects system preference |
| `useHaptics()` | Haptic feedback methods (light, medium, heavy, success, error...) |
| `useTrayContext()` | Tray panel stack management (open, close, navigate) |

### Providers

- **`ThemeProvider`** — Global theme state, localStorage sync, system preference detection
- **`TrayProvider`** — Sliding tray panel stack (bottom sheets, side panels)

### Utilities

| Utility | Purpose |
|---|---|
| `cn()` | Smart Tailwind class merging (clsx + tailwind-merge) |
| `SPRING_CONFIGS` | All 9 spring presets |
| `MICRO_INTERACTIONS` | Hover/tap/focus animation presets |
| `getMaterialGradientCss()` | Get material gradient as CSS string |
| `getMineralGradientCss()` | Get mineral gradient as CSS string |
| `getFactionHexes()` | Get faction color pair |
| `getOriginHexes()` | Get origin gradient stops |
| `sampleAvatar(n)` | Pick from 10 sample avatars (wraps around) |

## 🚀 Quick Start

### Install

```bash
pnpm add @jokuh/gooey
```

### Import styles

```tsx
import "@jokuh/gooey/styles/globals.css";
```

### Use components

```tsx
import { Button, Avatar, Badge, MineralEffect } from "@jokuh/gooey";
import { ThemeProvider, useTheme } from "@jokuh/gooey";

function App() {
  return (
    <ThemeProvider defaultTheme="dark">
      <Avatar name="Hyke" originColor="aether" size={48} />
      <Button variant="primary">Let's go</Button>
      <Badge>New</Badge>
    </ThemeProvider>
  );
}
```
