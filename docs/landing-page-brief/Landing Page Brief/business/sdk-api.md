## Section 2 — What you can build

**Three cards:**

1. **Encrypted memory in your product**
   Add Spine-style encrypted memory to your app. Per-user keys. TEE-backed compute. Full export.

2. **Agentic primitives**
   Spawn a Sidekick agent inside your product. Memory-aware, scope-aware, deterministic where it must be.

3. **ZK attestations**
   Issue and verify Zero-Knowledge attestations natively. Prove a fact about a user without learning the underlying data.

---

## Section 3 — What's in the SDK

**Body (70 words):**
The Jokuh SDK ships in JavaScript / TypeScript first, with iOS and additional language bindings in active development. The API exposes the same surface from any environment that supports HTTPS.

You get: Spine read/write, Pod scopes, Sigil-aware authentication, Sidekick agentic runtime, attestation issuance and verification, Wallet integration, and event hooks for streaming computation results back into your UI.

---

## Section 4 — Integration shape

**Body (70 words):**
The SDK is designed so a real product can be built on top of it without leaking through. Plaintext memory never crosses the network. Computation runs in a TEE — yours, or one Jokuh hosts. Identity is attested at the boundary, not assumed.

If you can ship a regular SaaS application, you can ship a sovereign one with Jokuh underneath.
